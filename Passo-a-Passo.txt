Primeiro passo:

Criou uma conta no github

Segundo passo:

Instalar o git caso não venha instalado, como verificar (git version)

Terceiro passo:

Criar um repositório dentro do github

Quarto passo:

Escolher uma pasta para colocar o projeto

Quinto passo:

Copiar url https disponibilizada no github (https://github.com/JonathanDSLima/AulaGit.git)

Sexto passo:

Abrir o terminal dentro da pasta

Sétimo passo:

Rodar o comando git clone nome_do_projeto (https://github.com/JonathanDSLima/AulaGit.git)

Oitavo passo:

Abrir a pasta direto no vscode

Nono passo:

Começar a colocar os arquivos

Décimo passo:

Rodar o comando git status que verifica os arquivos novos, removidos e alterados

Décimo primeiro passo:

Rodar comando git add . para adicionar tudo que foi incluso, removido e alterado na subida para o git
Caso o comando git status for rodado novamente, os arquivos antes vermelhos, ficaram verdes.

Décimo segundo passo:

Rodar o comando git commit -m "Subindo arquivo txt com passo a passo do uso do git", o qual, declara o que foi feito nas alterações
adicionadas anteriormente no comando git add .

Décimo terceiro passo:
Rodar o comando git push origin main para subir os arquivos que foram commitados anteriormente (git push origin nome da branch que existe no github)

Passos avançados de gitflow:

Primeiro passo:

Rodar o comando git checkout -b nome-branch para criar uma branch nova para desenvolvimento (ex: git checkout -b login)

Segundo passo: 

Rodar todos os comandos para subir uma alteração git status, git add ., git commit -m "Alteracoes feitas", git push origin login (ao inves de login será o nome da nova branch)
